# Wireframe: дашборд проекта и блок «Мой вклад»

Схемы основаны на шаблоне `internal/web/templates/dashboard.html`. Страница «Мой вклад» (`/projects/{id}/authors/{aid}`) использует тот же шаблон в режиме `AuthorView`: блоки, относящиеся ко всему проекту, скрываются. Обозначения: `[ ]` кнопка/поле, `▲▼` направление изменения, `█` столбец графика.

### Соответствие зон данным и метрикам

| Зона | Источник данных | Метрики / логика |
|---|---|---|
| (1) Заголовок, статус синхронизации | таблица проектов (`SyncStatus`, `LastSyncAt`, `SyncError`) | — |
| (2) Фильтры | query `days`, `from`, `to`, `team` | `app.ParsePeriod`, валидация from ≤ to |
| (3) KPI-плитки | `metrics.Summary` + `analysis.Trends` | ключевые из 22 метрик; дельта против предыдущего периода, вердикт учитывает направление «выше/ниже — лучше» |
| (4) Рекомендации | `analysis.Recommend` | bus_factor, mr_lead_time_median_h, first_review_median_h, large_mr_share и др.; уровни critical/warning/info/good |
| (5) Графики | JSON `#chart-data` (Git + провайдер) | `commits` по неделям, `mr_lead_time_median_h` по неделям, баллы Zerocracy |
| (6) Тепловая карта | коммиты по дню недели и часу (местное время автора) | `off_hours_share`, `weekend_share` |
| (7) Владение кодом | владелец файла = автор большинства изменённых строк | `bus_factor`, число отслеживаемых файлов |
| (8) Вклад разработчиков | персональный срез `Snapshot.Authors` | commits, active_days, median_commit_size, test_ratio, message_quality, mr_merged, lead time, reviews_given, issues_closed |
| (9) Zerocracy | `zerocracy.Evaluate` + журнал событий | политика баллов (см. [zerocracy.md](zerocracy.md)) |
| (10) Распределение задач | `zerocracy.Suggest` + открытые задачи провайдера | опыт (файлы, метки) × нагрузка |
| (11) Горячие точки | `Snapshot.Hotspots` | частота изменений файла, число авторов |
| (12) Таблица метрик | `metrics.Definitions` | описание формулы каждой из 22 метрик |

Состояния: пустой проект (нет синхронизации) — карточка «Данные ещё не загружены»; идёт синхронизация — бейдж «⟳ синхронизация…» и автообновление; ошибка — бейдж и текст ошибки под ним.

## B. Детальный блок: «Мой вклад» (`/projects/{id}/authors/{aid}`)

```
+--------------------------------------------------------------------------------+
| ← Весь проект                                                                   |
| Мария Петрова                                        [ok] обновлено 5 мин назад |
| 30 авг — 29 сен · сравнение с предыдущим периодом                               |
+--------------------------------------------------------------------------------+
| [7 дн][14 дн][30 дн][90 дн]  с [..] по [..]   [Показать]      (без выбора команды)|
+--------------------------------------------------------------------------------+
| KPI (персональные)                                                              |
| Коммиты 42 ▲ +8% | Акт. дни 15 | MR влито 5 | Ревью 9 | С тестами 70% | ...      |
+--------------------------------------------------------------------------------+
| Выводы и рекомендации (по личному срезу)                                        |
+--------------------------------------------------------------------------------+
| Коммиты по неделям  █ █ ▄ █    | Lead time MR по неделям (если есть данные)     |
+--------------------------------------------------------------------------------+
| Когда идёт работа (тепловая карта личной активности)                            |
+--------------------------------------------------------------------------------+
| Мой вклад: баллы Zerocracy                                                      |
|  Мария   52 pts  38%  [MR +30] [ревью +9] [задачи +13]                          |
|  ▸ Журнал начислений: 2026-09-21 · MR !34 «Экспорт CSV» · +15                    |
+--------------------------------------------------------------------------------+
| Распределение открытых задач · Горячие точки · Все метрики и как они считаются  |
+--------------------------------------------------------------------------------+
```

Отличия от общего дашборда: скрыты выбор команды, график баллов всех участников, блок «Владение кодом» и таблица «Вклад разработчиков»; заголовок — имя автора; все метрики считаются только по нему.

| Зона | Данные | Замечание |
|---|---|---|
| KPI, таблица метрик | `Analyze` с `Scope{AuthorID}` | сравнение — со **своим** прошлым периодом, не с коллегами |
| Тепловая карта | коммиты автора | помогает заметить переработки |
| Баллы и журнал | `zerocracy.Evaluate`, события автора | каждая строка ссылается на MR/задачу-основание |

## Адаптивность и темы

- Сетка `kpis`, `charts`, `two-col` перестраивается в одну колонку на узких экранах; таблицы в `table-wrap` прокручиваются по горизонтали.
- Светлая и тёмная темы; графики и тепловая карта различимы в обеих.
- Доступность: `aria-label` у секций и canvas, скрытый текст (`sr`) у ячеек тепловой карты и уровней рекомендаций, вердикт не передаётся только цветом (значки ▲▼•).
