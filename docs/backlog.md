# Backlog TeamPulse (Сфера.Задачи)

Спринты по 3 недели. Роли: **TL** — Team Lead/PM, **BE** — Backend, **FE** — Frontend, **QA** — QA/документация. Оценки в story points (SP). Статусы: «Готово» — реализовано в коде; «К выполнению» — впереди. Таблицы можно копировать в Сфера.Задачи построчно (ID → ключ задачи, эпик → метка `epic::…`).

Связанные документы: [MVP и истории](mvp-and-user-stories.md) · [wireframe](wireframe.md) · [тест-кейсы](test-cases.md) · [презентация](presentation.md).

## Эпики

| Эпик | Цель |
|---|---|
| E1 Организация и дизайн | Команда, стек, MVP, данные, wireframe, правила безопасности |
| E2 Сбор данных | Git-парсер, хранилище, инкрементальная синхронизация |
| E3 Метрики и анализ | 22 метрики, тренды, рекомендации, защита от плохих данных |
| E4 Интеграция Т1 Код | Провайдер MR/ревью/задач |
| E5 Интерфейс и отчёты | Дашборд, «Мой вклад», отчёты, настройки |
| E6 Zerocracy | Баллы, журнал, подбор исполнителей |
| E7 Безопасность и эксплуатация | Аутентификация, CSRF, Docker, планировщик |
| E8 Качество и документация | Тесты, README, презентация, репетиция |
